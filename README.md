# 诡秘小窗 · Guimi Chat

一个微信风格的私人 AI 朋友聊天网站，使用 DeepSeek，支持可编辑的人物设定、上下文记忆、表情包和连续发送消息。

## 启动

需要 Node.js 24.5 或更新版本。无需安装额外运行依赖。

1. 将 `.env.example` 复制为 `.env`，填写自己的 DeepSeek API Key。
2. 在项目目录运行 `npm start`。
3. 浏览器打开 http://127.0.0.1:3210 。Windows 也可双击「启动网站.cmd」。

## 功能

- 微信风格聊天、头像和背景，适配手机屏幕。
- 支持连续发送文字和图片表情，回复结合最新消息。
- 人物设定与聊天风格可以编辑；回复 1～3 条。
- 近期上下文、旧消息摘要、手动长期记忆、备份导入导出。
- 页面前台空闲约 10 秒时可主动开口，不连续催促；设置中可关闭。
- Key 仅存本机服务端，不发送给浏览器。

## 使用范围

这是模拟角色聊天网页，不接入真实微信。人物回复与校园日常属于 AI 创作。

手机与电脑连接同一 Wi-Fi 后，使用电脑局域网 IP 的 3210 端口访问。电脑需保持运行；关闭网页后没有主动推送。

聊天记录保存在各自浏览器，不自动跨设备同步。换设备前导出备份。表情资源保存在服务器的 `public/assets/stickers`，迁移项目时一起保留。

本项目包含个人设定和用户提供的图片，默认用于私有仓库。图片不附带再分发授权。

## 检查

运行 `npm test`。主服务入口为 `server.mjs`；`worker.js` 是旧版部署原型，不包含完整功能。

`.env`、运行日志、聊天备份和本地预览截图不提交到 Git。

## 公网部署

主服务现已支持公开域名、HTTP 和 HTTPS，同一网址下的访问者可以直接打开和聊天，无须处在同一局域网。

在支持 Node.js 的部署平台选择本仓库，启动命令为 `npm start`，配置 `DEEPSEEK_API_KEY`；服务读取平台提供的 `PORT` 并监听 `0.0.0.0`。API Key 不要写入前端。

如果代理会把请求 Host 改为内部地址，再设置 `PUBLIC_ORIGIN=https://你的完整域名`（不加路径）。通常保持默认即可；不要为此启用任意跨域来源。

公网访客无法通过设置页替换或断开全站 API Key，线上 Key 在部署平台环境变量中管理。聊天仍各自保存在访客的浏览器中。聊天调用使用网站主人配置的 DeepSeek 账户额度，同时最多处理 8 个回复请求。

仅把代码上传到 GitHub 不会自动运行 Node 服务；已有部署请更新到最新版本后重新部署。静态托管或旧版 `worker.js` 不是此完整 Node 服务的替代品。
